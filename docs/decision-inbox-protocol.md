# Decision Inbox Protocol

This protocol defines the narrow file exchange used by Manual Package and the
legacy package-only Auto MCP compatibility mode.

It is intentionally smaller than a workspace MCP server. The web advisor can
read decision packages and submit advice. It cannot browse real project files,
run commands, change Git state, install dependencies, or implement its own
recommendations.

Connected Agent does not use this package protocol as its primary context path.
It uses `connected-agent` workspace tools with one-action approval gates and a
session-only hidden danger switch.

## Task Directory

Each task lives under:

```text
decision-inbox/tasks/<task-id>/
```

Required files and folders:

```text
metadata.json
package.md
advice/
fact-check-requests/
```

`<task-id>` must be a slug made from lowercase letters, numbers, and hyphens. Do not accept slashes, dots, spaces, URL encoding, parent-directory traversal, or hidden path names as task ids.

## Metadata

`metadata.json` stores routing and review state only. It must not contain secrets or full private project content.

Recommended fields:

- `task_id`
- `title`
- `status`
- `created_at`
- `updated_at`
- `created_by`
- `advisor_rounds`
- `risk_level`
- `allowed_inputs`
- `disallowed_inputs`
- `next_local_action`

Allowed statuses:

- `draft`
- `package_ready`
- `advice_submitted`
- `needs_local_fact_check`
- `review_complete`
- `closed`

## Package

`package.md` is the only required input for a web advisor in v1.

It should be self-contained and include:

- goal,
- verified facts,
- assumptions,
- constraints,
- privacy boundary,
- settled decisions,
- open questions,
- required output format.

It should not include:

- secrets,
- credentials,
- full private project dumps,
- browser data,
- local machine details that are not necessary for the decision,
- instructions that treat the advisor as an executor.

## Advice

Advisor output is written under:

```text
advice/<timestamp>-<advisor>.md
```

The advisor may recommend actions, but those recommendations are not authorization. Codex must import the advice, classify material recommendations as `Adopt`, `Adapt`, `Reject`, or `Need info`, and wait for current-user authorization before any side effect.

`submit_advice` must include:

- `task_id`: the decision task slug being answered,
- `advisor`: a non-empty stable advisor identifier,
- `timestamp`: generated by the server or supplied as `YYYY-MM-DDTHH-MM-SSZ`,
- advice content with an explicit non-authorization marker, for example:
  `External advice only. This is not authorization.`

If the non-authorization marker is missing, the server rejects the write with a
clear tool error instead of storing ambiguous advice.

## Fact Check Requests

If the advisor needs a local fact, it may write:

```text
fact-check-requests/<timestamp>.md
```

Fact-check requests should ask narrow questions about local evidence. They must not request broad filesystem access, shell access, secret inspection, or real project writes in v1.

## MCP Tool Mapping

Candidate v1 tools map to files like this:

- `list_decision_tasks`: list task ids and selected metadata fields.
- `get_decision_package`: read `package.md` for one task.
- `submit_advice`: create one Markdown file under `advice/`.
- `get_task_status`: read selected metadata and count advice/fact-check files.

`request_local_fact_check` remains part of the plain file protocol for local
experiments, but it is not exposed in the default Auto MCP Controlled Advisor
web tool surface. A web advisor asking for local facts must put those questions
inside the advice; Codex decides what to verify locally.

Each tool must validate the task id before touching the filesystem.

## Local Implementation

Current local implementation:

- `server/decision_inbox_store.py`: validates task ids, reads package/metadata, writes advice and fact-check requests.
- `server/decision_inbox_server.py`: exposes the legacy package/advice/status tools over stdio JSON-RPC.
- `server/connected_agent_server.py`: exposes Connected Agent workspace tools,
  one-action approval gates, the hidden danger switch, and deprecated
  read-only/full-agent profiles.
- `server/decision_inbox_http_server.py`: exposes legacy Auto MCP by default,
  routes to Connected Agent with `--mode connected-agent`, and keeps
  deprecated `read-only-project` / `full-agent` aliases. The HTTP wrapper
  supports bearer-token auth, OAuth Owner password approval, mode-aware OAuth
  state persistence, Origin checks, Host allowlisting, and an optional public
  HTTPS base URL for tunnel/reverse-proxy runs.
- `scripts/decision_inbox_doctor.py`: checks connector readiness and risk without printing bearer-token, Owner-password, or OAuth state-file values.
- `scripts/decision_inbox_preflight.py`: checks local/public endpoint reachability, OAuth metadata/challenge scope, and authenticated tool allowlists when a bearer or OAuth access token is available.
- `scripts/decision_inbox_tunnel_window.py`: opens, checks, reports, and closes a bounded Tailscale Funnel public window.
- `scripts/connected_agent_session.py`: starts, touches, checks, and closes a short
  Connected Agent task window with idle shutdown. The filename is legacy.
- `scripts/prepare_consultation.py`: creates a package-ready Ask First /
  legacy Auto MCP task from a natural-language user request. It rejects
  Connected Agent because that mode does not generate packages.
- `scripts/import_advice_review.py`: renders a review-only Codex import gate for the latest advice file.

The import helper does not classify recommendations by itself. It imports advisor text as data and reminds Codex to run `agent-decision-bridge` Import Mode before accepting, adapting, or rejecting advice.

## Negative Tests

Before connecting a web advisor to the server, verify:

- a task id cannot escape `decision-inbox/tasks/`,
- hidden files are not exposed,
- paths outside the inbox are rejected,
- advice cannot overwrite `package.md` or `metadata.json`,
- fact-check requests are not exposed as default Auto MCP web tools,
- submitted content is stored as data, not executed.
