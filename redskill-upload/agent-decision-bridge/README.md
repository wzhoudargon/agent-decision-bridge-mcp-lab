# Codex 外接最强助理 RedSkill 包

这个压缩包用于小红书 Red Skill / SkillHub 上传。

## Skill 信息

- 名称：codex外接最强助理
- Skill ID：agent-decision-bridge
- 推荐标签：效率工具、编程开发、内容创作、学习成长
- 简介：把 ChatGPT 网页端接入 Codex：Ask First 做外部深度咨询，Connected Agent 让网页端在短窗口内查看授权项目，Codex 保留本地核查和执行控制。
