# RedSkill 上传说明

用于小红书 SkillHub 上传的本地 Skill 目录：

```text
redskill-upload/agent-decision-bridge
```

当前包内只使用 RedSkill 支持的文本格式：`.md` 和 `.json`。之前的
`agents/openai.yaml` 已改为 `agents/openai.json`，因为当前支持列表里没有
`.yaml/.yml`。

不要上传整个 GitHub 仓库，也不要手动压缩 zip。把上面的本地 Skill 目录交给
RedSkill CLI，让 CLI 自己校验和打包。

## CLI 入口

从仓库根目录执行。当前 npm symlink 入口会静默退出，需要先解析到真实
`cli/index.mjs`：

```bash
SKILLHUB_CLI="${SKILLHUB_CLI:-$(realpath "$(command -v skillhub-upload)")}"
```

## Dry Run 验证

已验证命令：

```bash
"$SKILLHUB_CLI" \
  publish redskill-upload/agent-decision-bridge \
  --dry-run \
  --agent \
  --source original \
  --tag 效率工具 \
  --identifier agent-decision-bridge
```

期望关键载荷：

```text
status: dry_run
name: codex外接最强助理
skill_identifier: agent-decision-bridge
version: 1.0.0
description: 把 ChatGPT 网页端接入 Codex：Ask First 做外部深度咨询，Connected Agent 让网页端在短窗口内查看授权项目，Codex 保留本地核查和执行控制。
source: original / 原创
tag: 效率工具
content_tag_ids: 1001
bundle_sha256: generated by CLI
bundle_size_bytes: generated by CLI
```

注意：保留 `--identifier agent-decision-bridge`。如果不指定，当前 CLI 会从中文展示名推导出 `codex`，不是我们想保留的稳定 Skill ID。

## 上传命令

如果还没登录：

```bash
"$SKILLHUB_CLI" login --agent
```

登录后提交：

```bash
printf 'submit\n' | "$SKILLHUB_CLI" \
  publish redskill-upload/agent-decision-bridge \
  --agent \
  --source original \
  --tag 效率工具 \
  --identifier agent-decision-bridge
```

如果只想测试确认流程、不真正上传，把 `submit` 换成 `cancel`：

```bash
printf 'cancel\n' | "$SKILLHUB_CLI" \
  publish redskill-upload/agent-decision-bridge \
  --agent \
  --source original \
  --tag 效率工具 \
  --identifier agent-decision-bridge
```
