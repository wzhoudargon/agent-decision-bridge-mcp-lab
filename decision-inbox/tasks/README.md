# Decision Tasks

This directory holds the package-only task exchange for Decision Inbox MCP v1.

Use `_template/` for new tasks. Each task should contain:

- `metadata.json`
- `package.md`
- `advice/`
- `fact-check-requests/`

Do not put real project files, secrets, credentials, private emails, browser data, or full proprietary documents in this directory.
